# Small Business Item Manager
Small Business Item Manager is a Python application I built ot help manage inventory for my eBay shop and other small online selling projects.

Goal: add, view, and manage inventory without interacting without the need for spreadsheets or third-party services.

## Features
- Add items to inventory
- View and manage stored inventory
- Persistent inventory storage using SQLite
- Graphical User Interface built with Tkinter
- Terminal user interface for working directly from the command line
## User Interface
- Will include both GUI and TUI

## GUI
- Built with Python's Tkinter library

## TUI
- Terminal interface will provide the same functionality but for those who like to work within the command line

## Tech Stack
- Python
- Tkinter
- SQLite
